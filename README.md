# UrlExtractorPro


URL Extractor Pro :-

Extracts All URLs in Table Format on same page or new tab.

Filter results based on words from settings.

Settings => Toolbar Icon -> Settings.


Extracts All URLs based on Filter in Table Format  on same page or new tab.

Scrolls to Extracted Table (Optional).


Highlighting rows in the table for custom words/matches.

You can change highlighting colour.


Automatically Open Highlighted URLs as Foreground (default) or Background Tabs.
Default is Open 5 Highlighted Tabs, For More Matches there is confirmation dialog to continue.
